# Build Week source archive

These are unchanged historical documents and delivery records from
[`v1.0.0-build-week`](https://github.com/kekekewww/Echo-Canva/tree/c8fe24700b67861e2f64fbb8950e9281c0e13a3c),
commit `c8fe24700b67861e2f64fbb8950e9281c0e13a3c`. They record the original
Build Week implementation and decisions; their instructions, deadlines, phase
status, audit results, and product plans are not current maintenance policy.

The original relative paths are mirrored here. Original bytes are preserved,
including obsolete statements and links. [MANIFEST.json](MANIFEST.json) records
the original Git blob and SHA256 for every archived file. For original links
that leave this document archive, use the immutable upstream tree above.
