## 可重現入口和證據類型

- **Confirmed by Test**。固定 SHA 後以 repo 的 Node/pnpm lock 安裝，執行 `pnpm exec vitest run tests/unit/classic-baseline-capture.test.ts tests/unit/hybrid3d-visibility.test.ts tests/unit/hybrid3d-second-order.test.ts tests/unit/static-structure-cache.test.ts tests/unit/frame-acceptance.test.ts`。Classic fixture 是 D-052 核准後十組快照，投影欄位四捨五入至小數六位。Hybrid 一、二階與 seeded visibility oracle 另有回歸覆蓋。P5 stationary receiver benchmark 統計 connection rate、平均中頻能量與幀間變化，其測試驗證 seed、樣本和正規化，未收集延遲。[Classic 原始快照](../../../benchmarks/results/mvp-baseline.json) · [P5 benchmark test](../../../tests/unit/hybrid3d-receiver-connection-benchmark.test.ts)
- **驗收**。先 `pnpm build`，再執行 `pnpm exec playwright test tests/e2e/workspace.spec.ts --grep 'survives the full entity-limit project' --workers=1 --retries=0 --trace=off`。100 walls、8 Portals、4 sources、8 listeners，播放時以 3 次預熱切換和 24 次量測切換檢查有效 Worker 數、遞增 revision／sequence 及數值 finite。24 筆最近秩 p95 必須嚴格 **< 12 ms**，量測窗中所有被觀察到的 Long Tasks 必須 **≤ 50 ms**。模式往返與兩次 refresh 核對單一 context、四個 graphs 與資料保留。原始結果寫到 Playwright output 的 `worker-stress-metrics.json`。完整 suite 與各次零重試結果分別報告。[測試](../../../tests/e2e/workspace.spec.ts) · [維護驗收](../../../docs/ACCEPTANCE_TESTS.md) · [診斷流程](../../../docs/testing/ci-diagnostics.md)
- **指標範圍**。`data-worker-compute-ms` 在兩池中由 main 開始 dispatch 計到最後 shard 通過回覆驗證後、frame assembly 前，涵蓋 cold install、訊息／排程、Worker 求解與 handler 驗證的對應部分。計時以整毫秒 `Date.now()` 為預設，前段 coalescing 與後段 React、audible presentation、audio apply 不在同一個數字內。Shard max/total 是各 Worker 報的 elapsed time，total 包含平行重疊。沒有 Long Task 的樣本仍可有大量短工作或高 frame age，需另外測。 [Classic pool](../../../src/workers/classic-source-pool.ts) · [Hybrid pool](../../../src/workers/hybrid-direct-pool.ts)
- **診斷**。以 `BROWSER_DIAGNOSTICS=1` 收 Chrome CPU trace，與無 tracing 的驗收分開。可用 `E2E_SINGLE_ACOUSTIC_WORKER=1` 檢查 Chromium 報 HC3 時的單 Worker 分支。這個覆寫只影響容量公式。把主執行緒 render/GC、dispatch、Worker 核心和 callback 等階段對齊，保留失敗、fallback 和長尾樣本。W3C Long Tasks 目前是 Discontinued Draft，現有 Chromium gate 繼續依現行實作執行。[CI 診斷](../../../docs/testing/ci-diagnostics.md) · [規格狀態](../../raw/references/performance.md)
- **離線聲音**。現行 `tests/e2e/audio-rendering.spec.ts` 覆蓋離線 reverb、crossfade、source lifecycle、occlusion 頻譜，搭配 browser listening checklist。歷史產物 artifact 1.0 在來源 `dd6890b` 記錄 0.8 s 目標、0.82 s 估計、兩聲道峰值 0.00694 及 crossfade 最大相鄰變化 0.0282% 相對峰值。這批量測使用 `OfflineAudioContext`。實體裝置 continuity、主觀定位和房間校正需獨立驗證。[原始音訊證據](../../../benchmarks/results/mvp-baseline-audio.json) · [測試](../../../tests/e2e/audio-rendering.spec.ts) · [聽測](../../../docs/testing/browser-listening.md)
